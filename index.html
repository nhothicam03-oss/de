Xưởng mô hình 3DMở GLB/FBX (có xương), gizmo, vẽ texture, chỉnh UV, shape key, xuất GLB
Thả file .glb / .gltf / .fbx vào đây

Tệp

Công cụ

Chọn và gizmo

Phím tắt: W di chuyển, E xoay, R tỉ lệ, Esc bỏ chọn. Kéo ở chỗ trống để xoay camera.

Cọ vẽ

UV

Lệnh UV áp dụng cho cả mesh, quanh tâm (0.5, 0.5).

Shape key

Chọn “Sculpt key”, rồi kéo trên mô hình để đẩy ra. Giữ Alt để ép vào.
